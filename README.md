# EduViz — Universal Educational Visualization Engine

A software platform that converts educational problems, questions, concepts, diagrams, and learning material into interactive visual experiences.

## Vision

Student input → local AI reasoning → structured visualization specification → visualization engine → interactive 2D/3D/simulation/animation experience.

## Status

**Phase 0: Foundation** — Project scaffolding, documentation, and engineering setup.

## Quick Start

```bash
npm install
npm run build
npm start
```

## Development

```bash
npm run dev        # watch mode (tsc --watch)
npm run typecheck  # type-check without emitting
npm run lint       # ESLint
npm run test       # tests (Node.js built-in test runner)
```

See [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) for full development guide.
